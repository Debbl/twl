---
title: 编译器
description: 编译 cn、clsx、twMerge 模板，保持各自的语义。
---

从 `twl/macro` 导入，并配置打包器插件。

| 输入                       | 输出                          |
| -------------------------- | ----------------------------- |
| ``cn`p-2 p-4` ``           | `"p-4"`                       |
| ``clsx`p-2 p-4` ``         | `"p-2 p-4"`                   |
| ``twMerge`p-2 p-4` ``      | `"p-4"`                       |
| ``cn`p-2 ${value}` ``      | `__twl_cn("p-2", value)`      |
| ``clsx`p-2 ${value}` ``    | `__twl_clsx("p-2", value)`    |
| ``twMerge`p-2 ${value}` `` | `__twl_twMerge("p-2", value)` |

注释和静态空白在编译期移除。插值直接成为对应函数的参数，不再生成模板字符串或额外的拼接调用。
普通函数调用会改为从 `twl/runtime` 导入，未使用的宏导入会移除，产物不再依赖 `twl/macro`。

## 错误提示

编译器拒绝命名空间导入、遮蔽宏导入的局部绑定、注释内的插值。
错误信息包含文件路径和行号。

## 选项

| 选项      | 默认值              | 作用                                           |
| --------- | ------------------- | ---------------------------------------------- |
| `from`    | `['twl/macro']`     | 提供宏 API 的模块，包括自定义重导出模块。      |
| `include` | `/\.[cm]?[jt]sx?$/` | 要编译的文件，Next.js 使用自己的 loader 规则。 |
| `exclude` | `/node_modules/`    | 跳过依赖。                                     |

`twl/macro` 只有类型声明，必须经过编译。需要运行时模板支持时，直接使用 `twl`。
